|---|---|---|---|---|
| 画面 | URL 1つで開く1枚の画面全体。その中の部品は「コンポーネント」 | ページ(画面を指すとき), ビュー(画面を指すとき) | 画面 | 未確定 |
| 画面パス | 画面1つを開く URL のパス(例: /orders/:id)。バックエンドの「エンドポイント」と区別 | ルート(画面パスを指すとき) | 画面 | 未確定 |
| モーダル | 後ろの画面を操作できなくし、閉じないと戻れないウィンドウ | ポップアップ(モーダルを指すとき), ダイアログ | 画面 | 未確定 |
| サーバー状態 | サーバーから取得して画面が持っているデータの写し。再取得すると変わる | サーバーキャッシュ(画面が持つ写しを指すとき) | 状態 | 未確定 |
| 画面状態 | サーバーになく画面の中だけで使う値(開閉、入力中の値)。サーバー状態と区別 | UI状態, クライアント状態, ローカル状態 | 状態 | 未確定 |
| ブラウザストレージ | ブラウザに残しておく値(localStorage・sessionStorage・IndexedDB)。バックエンドの「キャッシュ」と区別 | ローカルキャッシュ(ブラウザストレージを指すとき) | 状態 | 未確定 |
| レスポンシブ基準幅 | レイアウトが切り替わる画面幅の値(例: 768px)。デバッガーの中断点と区別 | ブレークポイント(画面幅を指すとき) | スタイル | 未確定 |
| テスト識別子 | 自動テストが要素を探すために付けた `data-testid` の値。変えるとテストが壊れるので、決めたものだけ変える | テストID, QA ID, セレクター(テスト識別子を指すとき) | QA | 未確定 |
| トースト | 少しの間表示され、自動で消える通知 | スナックバー | 画面 | 未確定 |

| 入力検証 | 入力値が規則に合っているかを画面で先に確かめること。サーバー側の確認は別にある | バリデーション, 妥当性チェック | フォーム | 未確定 |
| 楽観的更新 | サーバーの応答前に画面を先に変え、失敗したら元に戻すこと | オプティミスティックUI | 状態 | 未確定 |
| レイアウトずれ | 後から表示された要素のせいで、見えていた内容が押されて動くこと | レイアウトシフト, 画面のガタつき | 性能 | 未確定 |
| 画面文言 | ユーザーに見える文字(ボタン名、案内、エラーメッセージ) | UIテキスト, コピー(画面の文字を指すとき) | 画面 | 未確定 |
| デザイントークン | 色・余白・文字サイズの値に付けた名前(例: color-primary)。コードに値を直接書かずこの名前を使う | スタイル変数 | スタイル | 未確定 |
| コンポーネント | 画面を構成する再利用できる部品(ボタン、カード、リスト) | | 画面 | 未確定 |
| ハイドレーション | サーバーが作った HTML にブラウザがイベント・状態を付けて動くようにすること | | レンダリング | 未確定 |
| スケルトン | データを待つ間、内容の場所を灰色の枠で見せる読み込み表示 | | 画面 | 未確定 |
| デバウンス | 続けて起きる入力が止まった後に1回だけ処理すること | | 性能 | 未確定 |
| アクセシビリティ | キーボード・スクリーンリーダーの利用者も画面を使えるかどうかの度合い | | 画面 | 未確定 |
