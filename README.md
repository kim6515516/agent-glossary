# agent-glossary

**AI가 쓰는 말을 내가 아는 말로 바꿔 주는 "낱말 사전"이에요.**

AI 도우미(Claude)와 함께 일하다 보면, 같은 것을 사람마다 다른 말로 부를 때가 있어요.
예를 들어 바꾼 것을 원래대로 돌려놓는 일을 나는 "원복", 친구는 "롤백", AI는 "revert"라고 불러요.
같은 것을 서로 다른 말로 부르면 헷갈리지요.

그래서 이 도구는 **"우리는 '되돌리기'라고 부르자"** 하고 정해 둔 낱말 사전을 AI에게 미리 보여 줘요.
그러면 내가 "원복"이라고 말해도 AI는 알아듣고, 대답할 때는 함께 정한 말 "되돌리기"를 써요.

그래도 나는 "원복"이 더 편하다면? **나만의 사전**에 "원복 = 되돌리기"라고 적어 두세요.
그러면 AI가 나에게 말할 때만 "원복"이라고 해 주고, 다른 사람도 읽는 글에는 "되돌리기"라고 써요.

## 사전은 세 권이에요

| 사전 | 누가 함께 쓰나요 | 어디에 있나요 | 언제 쓰나요 |
|---|---|---|---|
| 📘 모두의 사전 | 같은 일을 하는 모든 사람(예: 화면 만드는 사람, 서버 만드는 사람) | 이 도구 안 `glossaries/` 폴더 | 글을 쓸 때도, 말할 때도 |
| 📗 우리 반 사전 | 한 프로젝트를 함께 하는 사람들 | 프로젝트 안 `docs/glossary.md` | 글을 쓸 때도, 말할 때도 |
| 📙 나만의 사전 | 나 혼자 | 내 컴퓨터 `~/.claude/glossary/personal.md` | **AI가 나에게 말할 때만** |

**나만의 사전은 "별명 수첩"이에요.**
친구를 별명으로 부르더라도 출석부에는 진짜 이름을 쓰지요? 그것과 같아요.
AI는 나에게 말할 때만 내 별명을 쓰고, 다른 사람도 읽는 글(문서, 코드 설명)에는 꼭 진짜 이름을 써요.

**여러 사전에 같은 낱말이 있으면 나와 가까운 사전이 이겨요.**
AI가 나에게 말할 때는 나만의 사전 → 우리 반 사전 → 모두의 사전 순서로 찾아요.

## 사전은 이렇게 생겼어요

칸이 다섯 개인 표예요.

| 용어 | 뜻 | 쓰지 않을 말 | 영역 | 확정일 |
|---|---|---|---|---|
| 되돌리기 | 바꾼 것을 바꾸기 전 모습으로 돌려놓는 것 | 롤백, revert | 작업 | 2026-10-23 |

- **용어**: 앞으로 쓰기로 정한 말
- **쓰지 않을 말**: 같은 뜻이지만 쓰지 않기로 한 말
- **확정일**: 이 말을 쓰기로 정한 날

나만의 사전은 더 간단해요. "내가 부르는 말"과 "진짜 이름" 두 칸만 있으면 돼요.

| 내 말 | 대응 용어 | 메모 |
|---|---|---|
| 원복 | 되돌리기 | 예전 회사에서 쓰던 말 |

## 이 도구가 해 주는 일

1. **사전 미리 보여 주기** — AI와 대화를 시작할 때마다 세 권의 사전을 AI에게 먼저 읽혀 줘요.
2. **새 낱말 정리 돕기** — AI가 새 이름을 지어 썼다면, 그 말들을 표로 모아서 "이 이름 괜찮아요?" 하고 물어봐요.
   내가 "좋아" 하고 정해 주기 전에는 사전에 넣지 않아요.
3. **틀린 말 찾기** — 문서 안에 "쓰지 않을 말"이 숨어 있는지 찾아서 알려 줘요.

## 설치하기

Claude Code(AI 도우미 프로그램)에서 아래 두 줄을 입력하세요.

```bash
/plugin marketplace add kim6515516/agent-glossary
/plugin install agent-glossary --marketplace kim6515516/agent-glossary
```

- 첫 줄은 "이 가게를 알려 줄게" 하고 도구 가게 주소를 등록하는 거예요.
- 둘째 줄은 그 가게에서 이 도구를 가져오는 거예요.

설치한 다음에는 `/config`에서 **어떤 모두의 사전을 볼지** 골라요. 예를 들어 서버를 만드는 사람이라면 `common,backend`라고 적어요.

> 💡 친구들도 쓰게 하고 싶다면, 친구들도 각자 위 두 줄을 한 번씩 입력해야 해요. 프로젝트 설정에 적어 두기만 해서는 친구 컴퓨터에 저절로 깔리지 않아요.

설치하지 않고 먼저 써 보고 싶다면 이렇게 열면 돼요.

```bash
claude --plugin-dir /path/to/agent-glossary
```

## 쓰는 방법

AI에게 이렇게 말하면 돼요.

| 이렇게 말하면 | 이런 일을 해요 |
|---|---|
| "용어 정리해 줘" | AI가 새로 만든 말을 표로 모아서 보여 줘요. 내가 고른 것만 사전에 넣어요. |
| "용어 검사해 줘" | 문서에 "쓰지 않을 말"이 있는지 찾아 줘요. |
| "나는 되돌리기를 원복이라고 불러" | 나만의 사전(별명 수첩)에 적어 줘요. |

## 잘 되는지 확인하기

- 새 대화를 열고 `/context`를 입력해요. 목록에 사전이 보이면 잘 된 거예요.
- 틀린 말 찾기를 직접 해 보려면 이렇게 입력해요.

```bash
scripts/lint-glossary.sh docs/
```

두 글자 이하로 짧은 말(예: "실험")은 다른 뜻으로 쓰일 때가 많아서, "틀렸어요" 대신 "한번 확인해 보세요"라고만 알려 줘요.
일부러 써도 되는 곳은 `docs/glossary-lint-allow.txt` 파일에 적어 두면 더 이상 알려 주지 않아요.

## 약속

- **나만의 사전에는 새 낱말을 만들지 않아요.** 이미 있는 낱말에 별명만 붙여요. 새 낱말은 우리 반 사전이나 모두의 사전에서 함께 정해요.
- **많이 쓰는 별명은 올려 보내요.** 내 별명을 두 사람 넘게 쓰면 우리 반 사전에, 여러 반이 쓰면 모두의 사전에 올려요.
- **사전은 얇게 만들어요.** AI가 대화할 때마다 사전을 통째로 읽기 때문에, 한 권에 50줄 정도로 짧게 유지해요.
- **비밀은 적지 않아요.** 비밀번호나 사람 이름 같은 개인 정보는 사전에 넣지 않아요.

## 아직 정하지 못한 것

- 모두의 사전을 고를 때 글자로 적는 대신 목록에서 고르게 할지
- AI가 나에게 보고하는 말에도 "쓰지 않을 말"이 섞였는지 자동으로 검사할지
- 모두의 사전을 고칠 때 누가 확인해 줄지

## 폴더 안에 있는 것

| 폴더·파일 | 하는 일 |
|---|---|
| `glossaries/` | 모두의 사전들 (`common.md`, `backend.md`, `frontend.md`, `ai-eval.md`) |
| `hooks/hooks.json` | 대화를 시작할 때 사전을 AI에게 읽혀 주는 장치 |
| `skills/glossary/` | "용어 정리", "용어 검사"를 할 때 AI가 따르는 순서 |
| `scripts/` | 사전을 읽는 프로그램과 틀린 말을 찾는 프로그램 |
| `templates/` | 우리 반 사전, 나만의 사전을 처음 만들 때 쓰는 빈 양식 |
