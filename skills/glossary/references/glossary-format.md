# 용어집 표 형식

공용 도메인·프로젝트 층은 같은 다섯 열을 쓴다. 검사 스크립트는 3열(쓰지 않을 말)을 쉼표로 나눠 읽는다.

```markdown
| 용어 | 뜻 | 쓰지 않을 말 | 영역 | 확정일 |
|---|---|---|---|---|
| 잘못 걸림 | 정상 문장을 위반으로 잘못 판정하거나 막는 것 | 과차단, 오탐 | 공통 | 2026-10-19 |
```

- 용어는 한 개념에 하나. 같은 개념을 두 행으로 만들지 않는다.
- "쓰지 않을 말"에는 에이전트가 만들어 쓰던 말, 영어 음차, 비슷한 뜻의 다른 말을 모두 적는다.
- 영역은 공용 도메인 파일에서는 하위 분류(예: API, DB, 상태), 프로젝트 파일에서는 기능 영역을 적는다.
- 파일 끝에 "변경 이력" 표(날짜 | 내용)를 둔다.
- 매 세션 전부 올라가므로 파일당 50행 안팎을 유지한다. 넘으면 "활성"과 "이력"을 분리한다.

개인 층은 세 열이다. 뜻을 적지 않고 대응 용어만 적는다.

```markdown
| 내 말 | 대응 용어 | 메모 |
|---|---|---|
| 오탐 | 잘못 걸림 | 보안 쪽 습관 |
```

프로젝트가 공용 용어를 다른 뜻으로 쓰면 프로젝트 표에 "공용 용어 X 는 이 프로젝트에서 Y 로 쓴다"는 행을 둔다.
