# agent-glossary

[한국어](README.md) | 日本語

**AI が使う言葉を、自分の知っている言葉に置き換えてくれる「ことば辞典」です。**

AI アシスタント(Claude)と一緒に仕事をしていると、同じものを人によって違う言葉で呼ぶことがあります。
たとえば、変更したものを元の状態に戻すことを、私は「切り戻し」、同僚は「ロールバック」、AI は「revert」と呼びます。
同じものを違う言葉で呼ぶと混乱しますよね。

そこでこのツールは、**「私たちは『元に戻す』と呼ぼう」** と決めておいた辞典を、AI に前もって見せます。
すると私が「切り戻し」と言っても AI は理解し、返事をするときは一緒に決めた言葉「元に戻す」を使います。

それでも自分は「切り戻し」のほうが楽なら? **自分だけの辞典** に「切り戻し = 元に戻す」と書いておきましょう。
AI が自分に話すときだけ「切り戻し」と言い、他の人も読む文章には「元に戻す」と書きます。

## 辞典は3冊あります

| 辞典 | 誰と使う | どこにある | いつ使う |
|---|---|---|---|
| 📘 みんなの辞典 | 同じ仕事をするすべての人(例: 画面を作る人、サーバーを作る人) | このツールの `glossaries/ja/` フォルダ | 書くときも、話すときも |
| 📗 チームの辞典 | 1つのプロジェクトを一緒に進める人たち | プロジェクトの `docs/glossary.md` | 書くときも、話すときも |
| 📙 自分だけの辞典 | 自分ひとり | 自分のパソコンの `~/.claude/glossary/personal.md` | **AI が自分に話すときだけ** |

**自分だけの辞典は「あだ名手帳」です。**
友だちをあだ名で呼んでいても、名簿には本名を書きますよね。それと同じです。
AI は自分に話すときだけあだ名を使い、他の人も読む文章(ドキュメント、コードの説明)には必ず本名を使います。

**同じ言葉が複数の辞典にあれば、自分に近い辞典が優先されます。**
AI が自分に話すときは、自分だけの辞典 → チームの辞典 → みんなの辞典 の順に探します。

## 辞典はこんな形です

列が5つある表です。

| 用語 | 意味 | 使わない言葉 | 領域 | 確定日 |
|---|---|---|---|---|
| 元に戻す | 変更したものを変更前の状態に戻すこと | ロールバック, 切り戻し, revert | 作業 | 未確定 |

- **用語**: これから使うと決めた言葉
- **使わない言葉**: 同じ意味だけれど使わないと決めた言葉
- **確定日**: この言葉を使うと決めた日

自分だけの辞典はもっと簡単です。「自分の言葉」と「対応する用語」の2列があれば十分です。

| 自分の言葉 | 対応する用語 | メモ |
|---|---|---|
| 切り戻し | 元に戻す | 前の会社で使っていた言葉 |

## このツールがすること

1. **辞典を先に見せる** — AI との会話を始めるたびに、3冊の辞典を AI に先に読ませます。
2. **新しい言葉の整理を手伝う** — AI が新しい名前を作って使ったら、その言葉を表にまとめて「この名前でいいですか?」と聞きます。
   自分が「いいよ」と決めるまでは辞典に入れません。
3. **間違った言葉を探す** — ドキュメントに「使わない言葉」が紛れていないか探して知らせます。

## インストール

Claude Code(AI アシスタントのプログラム)で次の2行を入力してください。

```bash
/plugin marketplace add kim6515516/agent-glossary
/plugin install agent-glossary --marketplace kim6515516/agent-glossary
```

インストールしたら、`/config` で2つを選びます。

- **言語**(`language`): `ja` にします。最初は `ko`(韓国語)になっています。
  選んだ言語のみんなの辞典を読み、AI へのルールや間違った言葉の検査結果もその言語で出ます。
- **どのみんなの辞典を見るか**(`domains`): たとえばサーバーを作る人なら `common,backend` と書きます。

> 日本語の辞典は韓国語の辞典を元にした初版なので、「確定日」はまだ `未確定` です。日本語を使うチームが確認してから日付を入れます。

インストールせずに試したいときは、こう開きます。

```bash
claude --plugin-dir /path/to/agent-glossary
```

## 使い方

AI にこう話しかけます。

| こう言うと | こうなります |
|---|---|
| 「用語を整理して」 | AI が新しく作った言葉を表にまとめて見せます。自分が選んだものだけ辞典に入れます。 |
| 「用語を検査して」 | ドキュメントに「使わない言葉」がないか探します。 |
| 「元に戻すを、私は切り戻しと呼んでいる」 | 自分だけの辞典(あだ名手帳)に書き込みます。 |

## 動いているか確かめる

- 新しい会話を開いて `/context` を入力します。一覧に辞典が見えれば OK です。
- 間違った言葉の検査を自分で試すには、こう入力します。

```bash
CLAUDE_PLUGIN_OPTION_LANGUAGE=ja scripts/lint-glossary.sh docs/
```

2文字以下の短い言葉(例: 「実験」)は別の意味で使われることが多いので、「間違いです」ではなく「確認してください」とだけ知らせます。
わざと使ってよい場所は `docs/glossary-lint-allow.txt` に書いておけば、もう知らせません。

## 約束

- **自分だけの辞典では新しい言葉を作りません。** すでにある言葉にあだ名を付けるだけです。新しい言葉はチームの辞典かみんなの辞典で一緒に決めます。
- **よく使うあだ名は上に送ります。** 自分のあだ名を2人以上が使えばチームの辞典に、複数のチームが使えばみんなの辞典に上げます。
- **辞典は薄く保ちます。** AI は会話のたびに辞典を丸ごと読むので、1冊50行くらいに短く保ちます。
- **秘密は書きません。** パスワードや人の名前などの個人情報は辞典に入れません。

## フォルダの中身

| フォルダ・ファイル | 役割 |
|---|---|
| `glossaries/` | みんなの辞典。言語ごとのフォルダ `ko/`、`ja/` の中に `common.md`、`backend.md`、`frontend.md`、`ai-eval.md` |
| `hooks/hooks.json` | 会話を始めるときに辞典を AI に読ませるしくみ |
| `skills/glossary/` | 「用語の整理」「用語の検査」のときに AI が従う手順 |
| `scripts/` | 辞典を読むプログラムと、間違った言葉を探すプログラム |
| `templates/` | チームの辞典、自分だけの辞典を最初に作るときの空の様式(`ko/`、`ja/`) |
